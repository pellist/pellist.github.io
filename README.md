# PELLIST. GitHub Pages

This folder is prepared for the public repository `pellist/pellist.github.io`.
After GitHub Pages deployment, the intended free URL is:

`https://pellist.github.io/`

## Important privacy check before publishing

This public deployment copy has the home address, taxpayer ID, bank account
number, and bank account name removed. Those details remain only in the private
local website files. Do not copy them into this public repository.

## Publish

1. Sign in to GitHub as `pellist`.
2. Create a **public** repository named exactly `pellist.github.io`.
3. From this folder, initialize Git and push its contents to the repository's
   `main` branch.
4. In the repository, open **Settings → Pages** and select **GitHub Actions**
   as the build and deployment source.
5. Wait for the **Deploy static site to GitHub Pages** workflow to complete.
6. Open `https://pellist.github.io/` and confirm the page and contact details.
7. In Google Search Console, add the site and submit
   `https://pellist.github.io/sitemap.xml`.

The workflow deploys the static files on each push to `main`. The invoice and
receipt tools run in the visitor's browser; they do not store records on a
server or provide a centralized accounting system.
